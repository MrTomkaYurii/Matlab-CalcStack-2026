# Voxels_3D — 3D Воксельне моделювання фібрилярних структур

Цей модуль містить скрипти для тривимірного (3D) воксельного моделювання біологічних фібрилярних структур (наприклад, колагенових фібрил), розрахунку фазового набігу, орієнтації оптичних осей та поляризаційних характеристик світла при проходженні крізь багатошарові об'ємні середовища.

---

## 📂 Склад модуля

| Скрипт | Призначення | Опис |
|---|---|---|
| **`Calc_2026_3D_Voxels_c1_d.m`** | Моделювання: випадок 1 (ізотропний), детерміністичний | Розрахунок 3D воксельного розподілу фазового набігу для ізотропних фібрил із фіксованим (детерміністичним) просторовим розташуванням. Генерація перерізів XOY, XOZ, YOZ та збереження карт. |
| **`Calc_2026_3D_Voxels_c2_d.m`** | Моделювання: випадок 2 (анізотропний), детерміністичний | Розрахунок 3D структури з анізотропними оптичними осями (фіксовані кути орієнтації оптичних осей фібрил). Побудова та візуалізація матричних елементів. |
| **`Calc_2026_3D_Voxels_c2_r.m`** | Моделювання: випадок 2 (анізотропний), випадковий (random) | 3D моделювання багатошарових фібрилярних структур із випадковим розподілом оптичних осей та флуктуаціями діаметрів/положення фібрил. |
| **`Calc_2026_Voxels_Gavruliak.m`** | Обробка експериментальних/модельних шарів | Пакетна обробка кроків сканування (25 зрізів/кроків) для поляризаційних карт ($\alpha$, $\beta$, $r_{12}, r_{14}, r_{23}, r_{24}$) зразків Гавриляка. |
| **`calc_Voxels_TestRun_01.m`** | Тест візуалізації вокселів (куб) | Тестовий запуск побудови 3D куба вокселів за допомогою `im2patch` / `gpatch` з налаштуванням освітлення та прозорості граней. |
| **`calc_Voxels_TestRun_02.m`** | Тест ізоповерхонь вокселів | Тестування відображення воксельних карт з ізоповерхнями (`isosurface` / `isocaps`) для компактного представлення полів. |
| **`calc_Voxels_TestRun_03.m`** | Тест багатошарових вокселів | Тест пошарової візуалізації та побудови комплексних воксельних ансамблів для верифікації графічного рушія. |

---

## ⚙️ Основні параметри розрахунку (у конфігураційних блоках)

- `diameter`: діаметр фібрили в пікселях (за замовчуванням `56 px`).
- `number_of_fibrils_in_row`: кількість фібрил у шарі (за замовчуванням `6`).
- `optical_axis_3D`: орієнтація оптичної осі окремої фібрили.
- `optical_axis_multilayer_3D`: орієнтація оптичних осей для трьохшарової структури вздовж напрямків проникнення променя.
- `save_path_top`: коренева директорія для збереження згенерованих 3D фігур та масивів.

---

## 🚀 Як запускати

1. Відкрити потрібний сценарій у MATLAB (наприклад, `Calc_2026_3D_Voxels_c1_d.m` або `Calc_2026_3D_Voxels_c2_r.m`).
2. Перевірити параметри розмірності сітки та шляхи збереження (`save_path_top`).
3. Запустити скрипт:
   ```matlab
   Calc_2026_3D_Voxels_c1_d
   ```
4. Для швидкої перевірки коректності налаштувань графічного рендерингу (чи встановлені потрібні toolbox для `im2patch` / `gpatch`):
   ```matlab
   calc_Voxels_TestRun_01
   ```
