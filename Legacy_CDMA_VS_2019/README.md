# Legacy_CDMA_VS_2019 — Поляриметрія векторів Стокса, кругового дихроїзму та матриць Мюллера (2019)

Цей модуль містить скрипти розрахунку поляризаційних карт зразків біологічних рідин і тканин (2019 року), включаючи параметри вектора Стокса, круговий дихроїзм (CDMA, CDMP), фазові набіги ($\delta$), азимут та еліптичність поляризації.

---

## 📂 Склад модуля

| Скрипт | Призначення | Опис |
|---|---|---|
| **`calc__BODY.m`** | Головний пакетний оркестратор (2019) | Керуючий скрипт для послідовного проходу за списком біологічних зразків (ліквор, жовч, кров, міокард, плазма, нирка тощо) та запуску обраних обчислювальних функцій. |
| **`calc__MULLER.m`** | Розрахунок матриці Мюллера | Відновлення елементів матриці Мюллера з вихідних серій поляризаційних вимірювань. |
| **`calc__VS.m`** | Вектор Стокса (Stokes Vector) | Розрахунок координат та карт параметрів вектора Стокса ($S_1, S_2, S_3, S_4$) та ступеня поляризації (DOP). |
| **`calc__VS_CORREL.m`** | Кореляція вектора Стокса | Просторова кореляція та двоточкові залежності для компонент вектора Стокса. |
| **`calc__AZIMUTH.m`** | Карти азимута поляризації | Розрахунок просторового розподілу кута орієнтації поляризаційного еліпса (азимут $\alpha$). |
| **`calc__ELLIPTICITY.m`** | Карти еліптичності поляризації | Розрахунок просторового розподілу кута еліптичності ($\beta$). |
| **`calc__DELTA.m`** | Карти фазового набігу ($\delta$) | Обчислення фазового зсуву (лінійного двозаломлення) біологічного середовища. |
| **`calc__CDMA.m`** | Круговий дихроїзм (амплітудний) | Розрахунок матричних характеристик амплітудної кругової анізотропії (Circular Dichroism Mueller Amplitude). |
| **`calc__CDMP.m`** | Круговий дихроїзм (фазовий) | Розрахунок фазових характеристик кругової анізотропії (Circular Dichroism Mueller Phase). |

---

## ⚠️ Важлива примітка щодо кодування

Файл `calc__BODY.m` історично збережений у кодуванні **Windows-1251 (CP1251)**. При його ручному редагуванні сторонніми редакторами необхідно зберігати оригінальне кодування, щоб уникнути пошкодження кириличних рядків у назвах папок та коментарях.

---

## 🚀 Як запускати

1. Відкрити `calc__BODY.m`.
2. Налаштувати директорії зчитування зразків (`pathForRead`) та збереження (`pathForSave`).
3. Розкоментувати необхідну стадію розрахунку (наприклад, `calc__VS`, `calc__CDMA`, `calc__azimuth`).
4. Запустити скрипт у середовищі MATLAB:
   ```matlab
   calc__BODY
   ```
