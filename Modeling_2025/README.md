# Обчислювальний блок: Моделювання 2025 (`Modeling_2025`)

## Призначення
Блок математичного та фізичного моделювання просторових розподілів поляризаційних параметрів анізотропних біологічних середовищ (періодичні структури, фібрили, фазові набіги).

## Головний файл запуску
* **`Modeling2025_body.m`** — керуючий скрипт для пакетного моделювання. Задає розміри сітки (400×400), набори періодів фазових зсувів $T_{LB} \in \{50, 100, 200\}$ та орієнтацій оптичних осей $T_\rho \in \{50, 100, 150\}$, кроки сканування (5, 10, 20 px), ітерує по комбінаціях та викликає модулі розрахунку.

## Склад блоку та призначення скриптів
| Файл | Опис та математичний зміст |
| :--- | :--- |
| **`Modeling2025_body.m`** | Головна точка входу. Створює карти $\delta(x,y)$, $\rho(x,y)$, викликає функції моделювання та зберігає результат. |
| **`Modeling2025_MM.m`** | Розрахунок 1D перетинів та елементів матриці Мюллера $M_{ik}$ для змодельованих структур. |
| **`Modeling2025_MM_2D.m`** | 2D розрахунок повної матриці Мюллера (16 елементів) на двовимірній координатній сітці. |
| **`Modeling2025_alfa.m`** | Моделювання азимута $\alpha$ поляризації (1D сканування зі змінним кроком). |
| **`Modeling2025_alfa_2D.m`** | 2D координатний розподіл поляризаційного азимута $\alpha(x,y)$. |
| **`Modeling2025_betta.m`** | Моделювання кута еліптичності $\beta$ поляризації (1D профіль). |
| **`Modeling2025_betta_2D.m`** | 2D координатний розподіл еліптичності $\beta(x,y)$. |
| **`Modeling2025_Sensitivity_onePoint.m`** | Одноточкова чутливість поляриметричного детектування до варіацій оптичної осі та фазового зсуву. |
| **`Modeling2025_Sensitivity_twoPoint.m`** | Двоточковий диференційний аналіз чутливості при просторовому рознесенні точок спостереження. |
| **`Modeling2025_singularity_analisys.m`** | Детектування та аналіз поляризаційних сингулярностей (C-точки, L-лінії) у змодельованих спекл-полях. |
| **`harmonic_modulation.m`** | Моделювання гармонічної просторової модуляції фази та орієнтації фібрилярних пучків. |
