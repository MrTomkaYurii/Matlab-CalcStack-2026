# Перерахунок карт аргументу на кругову палітру CET-C6 (04.11.2026)

## Що сталося

Карти аргументу arg(f_ik) малювалися у MATLAB `hsv`. Вона кругова (0 і 2π одного
кольору), але нерівномірна за сприйняттям:

- жовтий, блакитний і пурпурний значно світліші за синій і червоний, тому на картах
  з'являються хибні смуги і «структура», якої в даних немає;
- рівний крок фази не дорівнює рівному кроку кольору;
- червоний і зелений плутаються при дальтонізмі, а в ЧБ-друці карта стає кашею.

Рішення: перейти на CET-C6 (Peter Kovesi, colorcet). Це кругова шестиколірна
веселка, схожа на hsv, але вирівняна за сприйняттям.

## Що змінено в коді

| Файл | Зміна |
|---|---|
| `core/cet_c6.m` | нова палітра 256×3 (генерує `make_cet_c6_table.py`) |
| `viz/viz_arg_cmap.m` | поелементні карти arg: `hsv` → `cet_c6` |
| `viz/viz_phase_mask.m` | маска фазового вікна: `hsv` → `cet_c6` |
| `paper_figures/cfg_figures.m` | `FIG.color.maps.color.arg`: `hsv` → `cet_c6` |

Модуль лишається у `jet`. Кругова шкала потрібна лише для самого аргументу (фаза,
середній напрям). Для АКФ, PSD і вейвлета arg та для статмоментів (СКВ, асиметрія,
ексцес) кругова шкала не потрібна, там лишається `jet`.

Статмоменти, result.mat і таблиці від палітри не залежать і не перераховуються.

## Що перемальовується

Вивід іде в `C:\August 2026-Results-2` з **тими самими шляхами та іменами**, що в
`C:\August 2026-Results`.

**Етап A — поелементні рисунки** (`Розрахунки - Двот. елем. ММ\...`), лише ті, де є

**Етап B — скомпоновані рисунки** (`Розрахунки - Скомпановані рисунки - Перераховано 18.09\...`):
лише Fig1 і Fig7, бо тільки в них є карти arg. Займає близько 1 год.

Не перемальовуються: Fig2–Fig6, вейвлет, АКФ/PSD, скелетон, мультифрактал,
`fXX_stats.txt`.

Суфікс `_jet` в іменах файлів лишається: він стосується палітри модуля, а ще так
файли просто перезаписуються при копіюванні.

## Як запустити

1. Один раз згенерувати палітру:

   ```bash
   python -m pip install colorcet
   ```

   ```bash
   python make_cet_c6_table.py
   ```

2. У MATLAB із цієї теки: `run_Recolor_Arg`. Щоб почати одразу з етапу B:
   `run_Recolor_Arg(2)`.
3. Якщо вимкнули світло, просто запустити ще раз:
   - етап A пропускає теки з `viz_c6_done.txt`;
   - етап B пропускає вже збережені рисунки;
   - журнал етапів: `C:\August 2026-Results-2\recolor_journal.txt`.
