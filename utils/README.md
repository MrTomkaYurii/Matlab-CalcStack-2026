# utils — Спільні допоміжні утиліти

Ця папка містить спільні високопродуктивні математичні та візуалізаційні функції, які викликаються іншими модулями проєкту (зокрема `DvotMM_2025` та `Legacy_CDMA_VS_2019`).

---

## 📂 Склад утиліт

| Файл | Опис |
|---|---|
| **`ultra_fast_xcorr2.m`** | **Ультрашвидка 2D автокореляція / взаємна кореляція (xcorr2)**.<br>• Оптимізована під 16-потокові процесори (`maxNumCompThreads(16)`).<br>• Використовує приведення до типу `single` та доповнення нулями до степенів двійки (`nextpow2`) для максимальної швидкості FFT.<br>• Налаштовує FFTW planner (`fftw('planner', 'measure')`).<br>• Дозволяє обчислювати 2D АКФ для великих матриць на кілька порядків швидше за стандартний `xcorr2`. |
| **`nhist.m`** | **Нормалізовані покращені 1D/2D гістограми**.<br>• Авторська функція (Jonathan Lansey) для зручної побудови гістограм щільності ймовірностей, порівняння кількох розподілів та накладання оцінок щільності (KDE). |

---

## 🔗 Підключення до скриптів

Щоб використовувати ці утиліти з будь-якого іншого скрипту, додайте наступний рядок на початку вашого файлу:

```matlab
addpath(fullfile(fileparts(mfilename('fullpath')), '..', 'utils'));
```
