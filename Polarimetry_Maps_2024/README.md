# Polarimetry_Maps_2024 — Одноточкова поляриметрія та карти матриць Мюллера (2024)

Цей модуль призначений для розрахунку двовимірних карт елементів матриці Мюллера з вихідних поляриметричних інтенсивностей (поляризаційно-фільтрованих зображень), їх просторового кореляційного аналізу (АКФ 2D, PSD за напрямками), сегментації та спектрального вейвлет-аналізу.

---

## 📂 Склад модуля

| Скрипт | Призначення | Опис |
|---|---|---|
| **`calc_Muller_Matrix_Elements.m`** | Реконструкція матриці Мюллера | Зчитування 16 поляризаційних фільтрацій (`0-0`, `0-45`, `0-90`, `0-135`, `0-prav`, `0-liv` тощо) та обчислення просторових розподілів усіх 16 елементів матриці Мюллера $M_{11} \dots M_{44}$. |
| **`calc_Corr_Func_2D_2024.m`** | 2D автокореляційний аналіз (2024) | Розрахунок двовимірної просторової автокореляційної функції (2D АКФ) поляризаційних карт з оцінкою кореляційного радіуса та напівширини (HWHM). |
| **`calc_Corr_Func_2D.m`** | Базовий розрахунок 2D АКФ | Спрощена функція швидкої просторової автокореляції полів. |
| **`calc_Akf_Psd_Stat_Directions.m`** | Спрямована АКФ та спектральна густина потужності (PSD) | Аналіз профілів АКФ та спектральної густини потужності вздовж виділених напрямків ($0^\circ, 45^\circ, 90^\circ, 135^\circ$) з розрахунком статистичних моментів (1–4 порядків). |
| **`calc_Histograms.m`** | Статистичний аналіз розподілів | Побудова нормалізованих гістограм розподілів інтенсивностей та розрахунок статистичних параметрів: середнє, дисперсія, асиметрія, ексцес. |
| **`calc_Segmentation.m`** | Сегментація зображень | Розбиття великих мікроскопічних карт на локальні квадрати/сектори заданого розміру (патчі) для оцінки неоднорідності зразка. |
| **`calc_To_Polar_Coordinates.m`** | Перетворення в полярні координати | Перетворення прямокутних матриць у полярну систему $(r, \theta)$ для виявлення радіальних закономірностей. |
| **`calc_Wavelet.m`** | Вейвлет-аналіз | Просторово-частотна фільтрація та розклад поляризаційних карт із використанням вейвлет-перетворення для виявлення характерних масштабів структур. |
| **`fillDataSet.m`** | Допоміжне формування структур даних | Сервісна функція для агрегації результатів у загальну структуру `data_sets`. |

---

## 🚀 Як використовувати

1. Підготувати набір сирих поляризаційних кадрів (`.bmp` або інший формат) у відповідній директорії.
2. Встановити змінні шляхів у робочому просторі (`readTomka`, `saveTomka`) або викликати відповідні функції:
   ```matlab
   readTomka = 'C:\Path\To\Raw_Images\';
   saveTomka = 'C:\Path\To\Output\';
   calc_Muller_Matrix_Elements;
   ```
3. Для кореляційного чи спектрального аналізу отриманих матриць викликати:
   ```matlab
   calc_Corr_Func_2D_2024(image_data, savePath, sampleName);
   calc_Akf_Psd_Stat_Directions(image_data, savePath, sampleName);
   ```
