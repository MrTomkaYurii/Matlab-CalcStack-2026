# DvotMM_2025 — Двоточкова поляриметрія та матриці Мюллера (2025)

Цей модуль реалізує алгоритми та пайплайни двоточкової поляриметрії для розрахунку кореляційних та двоточкових параметрів матриці Мюллера, а також параметрів поляризації (азимута $\alpha$ та еліптичності $\beta$) на біологічних тканинах і рідинах.

---

## 📂 Склад модуля

### Головний оркестратор
- **`calc_2025_BODY.m`**  
  Керуючий скрипт для пакетної обробки набору зразків (біологічні тканини: Ендометрій, Жовч, Ліквар, Міокард, Мозок, Печінка, Плазма, Простата, Синовіальна рідина, Шийка матки). Ітерує по зразках і кроках просторового зсуву між точками (`step = 1, 5, 10` або інші).

### Обчислювальні скрипти двоточкових параметрів
- **`calc_2025_DvotMM_1D_Circular.m`**  
  Розрахунок двоточкових параметрів елементів матриці Мюллера вздовж колових траєкторій сканування (Circular scanning) для дослідження радіальної та азимутальної симетрії.
- **`calc_2025_DvotMM_1D_OX.m`**  
  Розрахунок одновимірних двоточкових функцій елементів матриці Мюллера вздовж напрямку $OX$.
- **`calc_2025_DvotMM_2D_RealBT.m`**  
  Двовимірний (2D) кореляційний аналіз матриць Мюллера для реальних зразків біологічних тканин (АКФ, просторові перерізи).
- **`calc_2025_DvotMM_2D_RoDelta.m`**  
  Розрахунок 2D розподілів та двоточкових зв'язків для оптичної анізотропії: орієнтації оптичних осей ($\rho$) та фазового зсуву ($\delta$).
- **`calc_2025_DvotMM_Azimuth_Ellipticity.m`**  
  Розрахунок двоточкових взаємозв'язків для азимута $\alpha$ та еліптичності $\beta$ стану поляризації.

### Візуалізація
- **`calc_2025_vis_DvotMM.m`** — побудова графіків, гістограм та профілів двоточкових матричних елементів.
- **`calc_2025_vis_DvotMM_Circular.m`** — візуалізація колових профілів та кутових діаграм.
- **`calc_2025_vis_Azimuth_Ellipticity.m`** — графічне відображення карт та функцій розподілу $(\alpha, \beta)$.

### Допоміжний та інформаційний аналіз зразків
- **`calc__INFO_About_Sample.m`** — розрахунок базових статистичних характеристик вхідних зображень (середнє, дисперсія, асиметрія, ексцес).
- **`calc__INFO_About_Sample_Circular.m`** — статистика для кругових областей інтересу.
- **`calc_Full_Information.m`** — розбиття зображення на сектори/патчі, розрахунок АКФ, ПФ (PSD), вейвлет-коефіцієнтів та фракталів.

## 🔗 Залежності

- Модуль автоматично підключає утиліти з папки `../utils/` (`ultra_fast_xcorr2.m`, `nhist.m`):
  ```matlab
  addpath(pathForCode);
  addpath(fullfile(fileparts(pathForCode), 'utils'));
  ```

---

## 🚀 Як запускати

1. Відкрити `calc_2025_BODY.m`.
2. Вказати робочі шляхи:
   - `pathForRead`: директорія із вхідними файлами зразків;
   - `pathForSave`: директорія для збереження результатів.
3. Розкоментувати потрібний тип розрахунку (наприклад, коловий або вздовж осі $OX$) у циклі за кроками:
   ```matlab
   calc_2025_DvotMM_1D_Circular(savePath, readPath, pathForCode, crop_size, step);
   ```
4. Запустити розрахунок:
   ```matlab
   calc_2025_BODY
   ```
