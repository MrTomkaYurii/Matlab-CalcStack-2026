# Структура проєкту обчислень поляриметрії та моделювання (MATLAB)

Цей репозиторій містить обчислювальні скрипти, моделі та аналітичні пайплайни поляриметрії біологічних тканин і рідин, матриць Мюллера, параметрів Стокса та 3D воксельного моделювання.

---

## 📁 Структура каталогів

### Основні блоки обчислень
- **[`august2026/`](./august2026)**  
  Актуальний пайплайн двоточкової поляриметрії та аналітики (Серпень 2026): розрахунок кроків сканування (orthogonal, XY, polar, generalized), фільтрація масок, розрахунок АКФ HWHM, мультифракталів та підготовка фігур до наукових статей.
- **[`july2026/`](./july2026)**  
  Попередній етап експериментів та пайплайнів (Липень 2026).
- **[`Modeling_2025/`](./Modeling_2025)**  
  Аналітичне та статистичне моделювання поляризаційних характеристик (2025): моделі матриць Мюллера, азимута $\alpha$, еліптичності $\beta$, сингулярностей, гармонічної модуляції та чутливості 1-точкових/2-точкових методів.
- **[`Voxels_3D/`](./Voxels_3D)**  
  Тривимірне (3D) воксельне моделювання фібрилярних структур: ізотропні та анізотропні моделі, фазовий набіг, багатошарові структури та візуалізація ізоповерхонь вокселів.
- **[`DvotMM_2025/`](./DvotMM_2025)**  
  Двоточковий аналіз матриць Мюллера для біологічних зразків (2025): сканування по колу (Circular) та лінії ($OX$), карти $\rho$ і $\delta$, та інформаційні характеристики зразків.
- **[`Polarimetry_Maps_2024/`](./Polarimetry_Maps_2024)**  
  Одноточкова поляриметрія (2024): відновлення 16 елементів матриці Мюллера, 2D АКФ, спрямовані АКФ/PSD ($0^\circ, 45^\circ, 90^\circ, 135^\circ$), сегментація та вейвлет-аналіз.
- **[`Legacy_CDMA_VS_2019/`](./Legacy_CDMA_VS_2019)**  
  Історичні розрахунки поляриметрії (2019): вектори Стокса ($VS$), круговий дихроїзм (CDMA, CDMP), фазові набіги ($\delta$), карти еліптичності та азимута.

### Допоміжні каталоги
- **[`utils/`](./utils)**  
  Спільні оптимізовані математичні функції: `ultra_fast_xcorr2.m` (багатопотокова 2D АКФ через FFTW) та `nhist.m` (нормалізовані гістограми).
- **[`plotly/`](./plotly)**  
  Інструменти та скрипти інтерактивної візуалізації за допомогою Plotly.
- **[`test/`](./test)**  
  Тестові та діагностичні скрипти.
